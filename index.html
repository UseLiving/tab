How we calculate

The receipt is arithmetic, not accounting. Here is what each line means, and where it can be wrong.

01 · READ

Public address only

You paste a public address. No wallet connection, no signature, and we never ask for a key or seed phrase.

02 · MATCH

Trades, not transfers

Only trades count. Transfers and other apps are set aside. Coins aped counts unique coins bought.

03 · ESTIMATE

Spent − back = net

SOL SPENT is SOL into buys, SOL BACK is SOL out of sells. NET is the difference. Fees get their own line, marked est.

Fees are always "est."

Fees are shown on their own line and never subtracted twice. Every fee figure carries est.

Rank is among printed wallets

"#48 of 1,204" means among wallets printed here. The denominator is always on the receipt.

This version is simulated

This bar generates each receipt from the address itself, so the same wallet always prints the same tab. It does not read real chain data.
